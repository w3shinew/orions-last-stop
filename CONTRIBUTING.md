# Contributing

Thanks for helping improve Galactic2.

1. Open an issue for substantial changes so scope can be discussed first.
2. Keep pull requests focused and explain the user-visible behavior.
3. Build with the documented CMake workflow and include test evidence.
4. Preserve the read-only-by-default safety model.
5. Update documentation when adding or changing commands.

Please do not include secrets, personal file contents, or private system paths in issue reports.
